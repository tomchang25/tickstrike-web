# src/shared/assets/

Store only package-ready runtime assets with demonstrated cross-feature ownership here. Feature-owned assets belong in `src/content/<feature>/assets/`, and application code must not import source material from the root `assets/` directory.

See `dev/foundation/platforms/web-react/standards/project_structure_standard.md` and `dev/standards/project_structure.addendum.md` for the canonical asset placement contract.
